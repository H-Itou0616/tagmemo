# たぐめも

タグ付きメモを作成・検索できるWebアプリです。
localStorage を利用し、ページを再読み込みしてもメモ内容が保持されます。

## 概要
- メモに「タイトル・本文・タグ」を付けて保存
- タイトル / 本文 / タグで検索可能
- タグをクリックするだけで、そのタグで即検索できます

## 主な機能
- メモの作成 / 削除
- localStorage へのデータ保存
- タイトル・本文・タグによる検索
- タグクリックによる検索
- 新しいメモを上に表示（降順ソート）
- 検索状態の表示とリセット

## 工夫した点
- 描画処理を `renderSavedNotes` に集約し、通常表示と検索表示を共通化
- 動的に生成される要素（削除ボタン・タグ）に対してイベント委譲を使用
- data 属性（data-tag）を使い、表示用の文字列と処理用の値を分離
- 検索中であることが分かるようにUI上へ状態を表示
- 誤操作防止のため、削除時に確認ダイアログを表示

## 使用技術
- HTML
- CSS
- JavaScript（ES6）
- localStorage

## 補足
JavaScript はフレームワークを使わず、  
DOM操作・イベント処理・配列操作の基礎を意識して実装しています。
